# Микро-сайт «все ссылки в одном месте»

Одна страница (`index.html`) — без зависимостей, сборки и фреймворков. Тёмная тема, плавающие градиентные пятна, стеклянная карточка, анимации.

## Что внутри

- Аватар + имя + ник
- Плашка с анимированным эквалайзером: «Я немая и общаюсь синтезом речи»
- Кнопки-ссылки: Telegram, VK, YouTube, Discord, GitHub, почта
- Адаптив под телефон (главный экран тут — телефон)

## Как отредактировать

Открой `index.html` в любом редакторе (хоть в Блокноте) — все места для замены помечены комментарием `<!-- ═══ ЗАМЕНИ ... ═══ -->`:

1. Имя, ник, буква на аватаре (или вставь своё фото по инструкции в CSS-комментарии).
2. Текст плашки — под себя.
3. `href="#"` у каждой кнопки → свои ссылки (ненужные кнопки просто удали).
4. `mailto:you@example.com` → своя почта.

Проверить локально: просто открой `index.html` двойным кликом в браузере.

## Как опубликовать на GitHub Pages (бесплатно)

1. Заведи аккаунт на github.com (если ещё нет).
2. Создай репозиторий с именем **точно** `ИМЯ_АККАУНТА.github.io`
   (например, для аккаунта `masha` → репозиторий `masha.github.io`).
3. Загрузи туда `index.html` (кнопка *Add file → Upload files*).
4. Через минуту сайт живёт по адресу `https://ИМЯ_АККАУНТА.github.io`

### Через командную строку (если поставила git)

```
cd Z:\Проекты\my-site
git init
git add .
git commit -m "мой сайт"
git branch -M main
git remote add origin https://github.com/ИМЯ_АККАУНТА/ИМЯ_АККАУНТА.github.io.git
git push -u origin main
```

## Кастомизация (по желанию)

Цвета меняются в начале CSS, в блоке `:root`:
- `--accent` — основной акцент (сиреневый)
- `--accent2` — второй акцент (бирюзовый)
- `--bg` — цвет фона

## Альтернативы (без кода вообще)

- **Taplink** (taplink.co) — российский аналог Carrd, есть русский язык
- **Linktree** (linktree.com) — просто ссылки списком
- **Carrd** (carrd.co) — красивый, но собирать придётся руками в редакторе
